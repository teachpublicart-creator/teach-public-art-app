TEACH PUBLIC ART — INSTALLABLE WEB APP STARTER

This is a working, branded PWA prototype using the existing 15 artwork records and links. It is NOT yet connected to the live Google Sheet. Refresh only redraws the built-in data.

TO PUBLISH FREE USING GITHUB PAGES
1. On a computer, sign in to github.com and create a PUBLIC repository named teach-public-art-app.
2. Upload the CONTENTS of this folder to the repository root (index.html, manifest.webmanifest, service-worker.js, icons/).
3. Under Settings > Pages, select Deploy from a branch, main, / (root), Save.
4. When GitHub Pages provides the HTTPS URL, open it on Android in Chrome. Open the three-dot menu and choose Install app or Add to Home screen (wording may vary).
5. Link the published app URL from teachpublicart.com.

IMPORTANT: Public GitHub Pages makes the source and built-in records public. Do not include personal/private information. Google Slides sharing permissions must allow intended teachers to view lessons. This prototype does not claim current availability of temporary artworks.

UPDATES: Editing artwork data in index.html requires republishing. A Google Sheets publishing connection is a separate next step. Avoid making your Google Sheet publicly editable.

BRAND: Orange/black logo supplied by TPA, original website copy used for the intro. Images remain placeholders.
